# Frontend Engineering
- Detecte framework, versão, package manager, build system, routing e estratégia de estilos antes de editar.
- Preserve arquitetura e convenções; não migre stack por preferência.
- Reutilize componentes quando houver repetição real; evite abstração prematura.
- Mantenha HTML semântico, estados explícitos e responsabilidades coesas.
- Evite dependências novas quando recursos existentes resolverem.
- Se React/Next.js estiver presente e `react-best-practices` disponível, consulte suas orientações.
- shadcn/ui é opcional e exige compatibilidade e justificativa.
- Preserve links, formulários, tracking, rotas e integrações existentes.
- Execute scripts reais de lint, typecheck, testes e build quando possível.
