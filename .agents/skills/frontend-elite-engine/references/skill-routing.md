# Skill and Tool Routing

| Need | Resource | Condition |
|---|---|---|
| Design research / system | UI/UX Pro Max | Skill detected |
| Creative direction | Frontend Design | Skill detected |
| Art direction / imagery | Taste Skill | Skill detected and prerequisites met |
| Critique / polish | Impeccable | Installed and initialized |
| UI/accessibility review | Vercel Web Design Guidelines | Skill detected |
| React performance | Vercel React Best Practices | React/Next.js project |
| Motion craft | Emil Design Engineering | Skill detected and motion useful |
| Components | shadcn/ui | Compatible project; adoption justified |
| Browser automation | Playwright | Browser/package/CLI configured |
| AI design generation | Google Stitch | Service and MCP configured |

Coordination:
1. UI/UX Pro Max + Frontend Design establish direction.
2. Taste enriches art direction, not product requirements.
3. Engineering implements.
4. Emil reviews motion; do not animate everything.
5. Impeccable and Vercel review the result.
6. Playwright verifies actual behavior.

If a skill is absent, continue using project conventions and general engineering practice, and report it as unavailable. Never claim it ran.

Stack notes: React Best Practices is irrelevant to plain HTML/CSS/JS. shadcn/ui is a component ecosystem, not a universal styling skill. Playwright is a test tool. Stitch requires service/MCP setup.
