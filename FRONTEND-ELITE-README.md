# Frontend Elite Engine — Quick Start

Comando principal no Antigravity:
```text
/frontend-elite-engine
```

## Redesign completo
“Redesenhe este site seguindo o Frontend Elite Engine. Preserve conteúdo e funcionalidades, estabeleça direção visual própria e valide desktop e mobile.”

## Nova landing page
“Crie uma landing page para [produto/serviço]. Audite o projeto, defina público, objetivo, conteúdo e Design System antes de implementar.”

## Auditoria sem alterações
“Execute uma auditoria Frontend Elite Engine. Não altere arquivos ainda: liste problemas por severidade, evidência e recomendação.”

## Refinamento
“Refine a página atual mantendo o Design System aprovado. Corrija hierarquia, espaçamento, responsividade, acessibilidade e estados.”

## Performance
“Faça auditoria de performance conforme a stack real. Não troque dependências sem justificar.”

Autonomia: implementação e correções rotineiras são automáticas. Deploy, commit, push, ações destrutivas, credenciais e mudanças arquiteturais de alto impacto exigem autorização.
