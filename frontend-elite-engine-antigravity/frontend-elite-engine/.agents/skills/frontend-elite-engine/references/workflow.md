# Detailed Workflow

1. Discovery: inspect git status, package manifests, framework config, routes, components, styles, assets, integrations, tests and deployment config.
2. Design intelligence: consult UI/UX Pro Max, Frontend Design and Taste Skill only if detected; choose one coherent direction and record tokens in `DESIGN.md`.
3. Technical design: match the existing stack; prefer existing dependencies; justify additions and high-impact changes.
4. Build: implement real content, responsive layouts, interaction states and accessibility; preserve existing behavior.
5. Refine: use Impeccable for critique/polish and Emil for motion review only if available and relevant.
6. Verify: use Vercel Web Design Guidelines, React Best Practices (React only), Playwright/browser tools (if configured); run actual project scripts and inspect screenshots when possible.
7. Report: changes, files, decisions, skills used, commands/results, limitations and pending work.
